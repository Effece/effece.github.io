Règles du Jeu Sans Nom

Règles générales

Le jeu sans nom se joue à deux joueurs. Il se déroule sur un plateau carré, de côté de longueur 5 ou 8. Toutes les cases sont des carrés, de même taille.
Les deux joueurs commencent à des coins opposés. Ils disposent d'une seule et unique pièce, qui peut se mouvoir sur toutes les cases qui lui sont adjacentes.
Chacun leur tour, les joueurs déplacent leur pièce d'après ses mouvements autorisés. Il est impossible de revenir sur une case déjà visitée auparavant (indépendamment du joueur y ayant été).

Objectif

La première possibilité pour gagner est de toucher son adversaire, c'est-à-dire se rendre sur la case sur laquelle il se trouve.
Un joueur perd s'il se retrouve entouré de cases déjà visitées. De ce fait, il est possible de gagner en bloquant le joueur adverse.

Variations

Les conditions peuvent être modifiées pour changer l'expérience de jeu.
La taille du plateau peut varier, et ne plus être un carré ; vous pouvez jouer sur un plateau rectangulaire. Un plateau aux cases hexagonales est envisagé.
Le nombre de joueurs pourra varier. Pour l'instant, il n'est possible d'y jouer qu'à deux joueurs.
Les modes de déplacements peuvent changer. Le jeu originel offre les déplacements sur les cases adjacentes, mais vous pouvez choisir de jouer sur toute une rangée, sur certaines cases proches...

Modes de déplacement

Le jeu propose cinq modes de déplacement. Les cinq premiers sont basés sur les déplacements aux Echecs.
Par défaut, le Roi : vous ne pouvez aller que sur les cases adjacentes (en diagonale y compris).
La Tour : vous vous déplacez à votre gré sur toute votre ligne ou votre colonne.
Le Fou : cette fois, sur vos diagonales ; attention de mettre les joueurs sur des cases de même parité pour permettre un jeu intéressant !
La Reine : une combinaison de la Tour et du Fou.
Le Cavalier : des déplacements de deux cases sur un axe puis une sur un autre axe.
